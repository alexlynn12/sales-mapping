Org Chart Builder

Build any reporting structure from scratch — positions, names, territories or team labels, and revenue — with no fixed levels and no tie to the sales-mapping tool's territories or geography. Click a box to edit it, the ✚ to add a report under it. Everything is saved in this browser as you go; use Save… for a file you can keep or share.

Org chart your structure
How it works
  • Everything is yours to define. There's one top position to start (rename it to whatever fits — CEO, Owner, Chief Revenue Officer). Add as many positions and as many levels as you want underneath it.
  • Add a report. Click the small ✚ on any box to add a new position reporting to it.
  • Edit a position. Click the box itself — set the title, the person's name (blank shows as vacant), a territory or team label, a colour, and who it reports to.
  • Revenue. Give any position its own revenue figure; each box also shows the rolled-up total for everyone under it, so a leader's box reflects their whole org.
  • Reorder. Hover a box with siblings and use the ◂ ▸ arrows to change the order they're drawn in.
  • Delete. From the edit dialog: move its reports up to whoever it reported to (or anywhere else), or delete the whole branch beneath it in one step.
  • Your work is kept between visits in this browser only — nothing is uploaded. Save… writes a JSON file you can move, share or reload later with Load…. Export CSV gives one row per position with rollups. Print / PDF prints the chart alone.
