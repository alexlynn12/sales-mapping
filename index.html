How it works
  • Your data stays yours. There is no server and no account. The published app carries synthetic demo numbers; "Use my data…" reads a JSON file straight off your machine and keeps it in this browser only.
  • Three levels. Area leader → optional district leader → territory manager. A territory not in a district reports straight to the area leader, so "direct reports" on each card is districts + direct territories.
  • Districts are yours to invent. Shift-click territories on the map, then "new district from these", or use the Districts tab. Deleting a district returns its territories to the area.
  • Areas can be added, renamed, recoloured and deleted. Click an area's name to rename it. Deleting one asks where its territories should go, so nothing is ever orphaned.
  • Names. Click any box in the org chart to set the person's name and title; the territory and planned-add tables have name fields too. Blank shows as vacant.
  • Your work is kept between visits. Where every territory sits, your districts, the names you type and any splits are written back to this browser after each change, so a refresh or a closed tab picks up where you left off. The bar above shows when it last saved; Discard throws it away and starts from the dataset as it came. It never leaves your machine, and it is per-browser — use Save… for a file you can move or share.
  • Splitting. A territory spanning several states is one person, so the whole patch moves together. If you need the states apart, click it and choose ⑂ split — pick which states move, how much revenue goes with them, and where the new territory sits. That is one more head, and the dialog tells you so first.
  • Grey states are not covered by any territory. Click one and choose give it coverage to attach it to a rep's patch — that adds no revenue and no head, it just closes the gap.
  • Checks run continuously — contiguity, leaders' home markets, same-metro pairs, and adds separated from their territory.
  • Colours. The first seven are colour-blind validated against each other; past that, identity relies on the labels, and you'll see a note.
  • Save… writes a JSON file of the whole structure; Load… brings it back. Export org CSV gives one row per person with who they report to. Print / PDF prints the org chart alone.
